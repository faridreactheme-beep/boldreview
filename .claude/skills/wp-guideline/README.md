# wp-guideline

Claude Code skill for WordPress.org Plugin Directory compliance reviews.

## Install/use

Copy the `wp-guideline` folder into the Claude skills directory used by your Claude Code setup.

The main skill file is:

`wp-guideline/SKILL.md`

Use it whenever you ask Claude to:
- audit a WordPress plugin for WordPress.org
- review Free vs Pro architecture
- check trialware
- audit external requests/tracking
- review admin notices
- check bundled libraries
- review readme/tags
- prepare a plugin for submission
- perform a security + WordPress.org compliance review
